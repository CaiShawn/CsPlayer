# CsPlayer v0.1.3 设计文档

相对 v0.1.2 的增量范围。基线见 `V0.1.1_DESIGN.md` / `V0.1.2_DESIGN.md`。
本版两项主题：**搜索**、**右键菜单（可自定义）**。均为当前代码未实现功能。

> 版本路线：v0.1.2 设置模块（已完成）→ **v0.1.3 搜索 + 右键菜单** → v0.1.4 登录凭证持久化（`V0.1.4_DESIGN.md`）。
> 依赖 v0.1.2 沉淀的 prefs 读写层（`settingsStore`）与主题 token，右键菜单配置复用 `csplayer:prefs:*`。

## 1. 目标

1. 接通顶栏**搜索**：单曲 / 专辑 / 歌手 / 歌单，进入结果页并可直接播放。
2. 实现**自定义右键菜单**：覆盖列表、卡片、队列等场景，条目可按用户偏好增删排序。

## 2. 功能范围

### 2.1 搜索

顶栏搜索框从占位改为真实功能。

**交互**

1. 输入防抖 300ms；`Enter` 或点放大镜提交。
2. 有关键字时跳转 `/search?q=...`（可刷新、可分享 URL）。
3. 无关键字聚焦时可显示「最近搜索」（本地存 10 条，可清空）。
4. 全局快捷键：`/` 或 `Ctrl+K` 聚焦搜索框（输入框内不劫持）。

**结果页 `/search`**

| Tab | 内容 | 主操作 |
|-----|------|--------|
| 单曲 | 表格：曲名 / 歌手 / 专辑 / 时长 | 播放、下一首播、加入队列、喜欢 |
| 专辑 | 封面网格 | 进 `/album/:id` |
| 歌手 | 头像 + 名称 | 进歌手页（见下） |
| 歌单 | 封面网格 | 进 `/playlist/:id` |

- 顶栏输入与结果页关键字双向同步；结果内改关键字即时重搜。
- 分页或「加载更多」；空结果显示空态（区分「无结果」与「请求失败」）。
- 单曲支持「播放全部」（搜索结果作为队列）。

**后端**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | `kw`、`type=song\|album\|artist\|playlist`、`limit`、`offset` |

- 映射 SDK 搜索接口（`search_default` 等，以 `MusicLibrary` 为准）。
- 响应统一为 `{ items, hasMore, total }`；单曲映射 `SongSummary`，专辑/歌单复用 `AlbumBrief` / `PlaylistBrief`。
- 短 TTL 缓存（如 60s，key 含 `kw+type+page`），避免重复打上游。

**歌手页（可选最小闭环）**

- 路由 `/artist/:id`：热门歌曲 + 专辑列表；本版可先做「查看歌手」只读页，不做关注/收藏。
- 若工期紧，歌手 Tab 点击可先弹「即将推出」，优先保证单曲/专辑/歌单。

### 2.2 右键菜单（可自定义）

**目标**：在应用内任意可操作对象上 `contextmenu` 弹出**自定义菜单**（阻止浏览器默认菜单），条目与顺序可由用户配置。

**触达对象**

| 对象 | 代表位置 |
|------|----------|
| 歌曲行 | 我喜欢、歌单/专辑详情、搜索结果、排行榜 |
| 播放队列项 | 右侧队列面板 |
| 当前曲 | 播放条封面 / 歌名区 |
| 专辑卡片 | 唱片架、搜索、音乐库 |
| 歌单卡片 | 音乐库 |

**内置动作（按对象过滤后展示）**

| 动作 | 歌曲 | 专辑 | 歌单 | 说明 |
|------|:----:|:----:|:----:|------|
| 播放 | ✓ | ✓ | ✓ | 替换队列或播该集 |
| 下一首播放 | ✓ | ✓ | ✓ | 插入队列 |
| 加入队列 | ✓ | ✓ | ✓ | 追加 |
| 喜欢 / 取消喜欢 | ✓ | | | 乐观更新 |
| 从队列移除 | ✓(队列) | | | 仅队列项 |
| 查看专辑 | ✓ | | | 跳转 |
| 查看歌手 | ✓ | ✓ | | 跳转 / 占位 |
| 复制链接 | ✓ | ✓ | ✓ | 复制站内路径 |
| 复制歌曲 ID | ✓ | | | 调试 / 分享 |

**自定义能力**

1. **设置 → 右键菜单**：按对象类型勾选「显示 / 隐藏」动作；上下拖拽排序；「恢复默认布局」。
2. 菜单末尾固定「自定义此菜单…」：直接跳设置对应分组，降低配置路径成本。
3. 配置存 `localStorage`（`csplayer:prefs:contextMenu`），与 v0.1.2 设置模块共用 prefs 层。
4. 隐藏全部非固定项时，仅剩「自定义…」与常用一两项，避免空菜单。

**菜单 UI**

- 定位：靠近光标，视口边缘自动翻转；`z-index` 高于队列面板。
- 交互：`Esc` / 点击外部 / 滚动关闭；支持方向键 + `Enter`（基础无障碍）。
- 样式：沿用顶栏下拉（`rounded-xl border-neutral-800 bg-neutral-900 shadow-xl`），图标位 + 文案；危险项（如移除）弱化红色。

**实现结构**

```
contextMenuStore   可见性、锚点坐标、目标 payload（song/album/playlist/queueIndex）
ContextMenu        通用浮层组件（portal）
contextActions     动作注册表 id → { label, icon, appliesTo, run }
prefs.contextMenu  每类对象的 id[]（有序 = 显示顺序）
```

- 右键时 `preventDefault()`，写入 store；组件树只挂一个 `ContextMenu` 实例。
- 动作 `run` 调现有 store / api（`playerStore`、`likesStore`、路由跳转），不新开服务层。

## 3. 后端 API 增量

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | 综合搜索，`type` 分型 |

右键菜单**无后端**（纯前端 prefs）。搜索缓存 TTL 建议加入 `settings.cache_ttl["search"] = 60`。

**SDK 对齐**

- 搜索类方法名以 `MusicLibrary` 源码为准（如 `search_default` / cloudsearch 系列）。
- 注意风控：搜索关键字过短或过频时在服务端限流（复用 `rate_limited`）。

## 4. 前端路由与组件

```
/login
/           → MainLayout
  /home
  /like
  /record
  /shelf
  /library
  /search   SearchPage（新）
  /settings
  /artist/:id  ArtistPage（新，可降级）
  /playlist/:id
  /album/:id
```

**新增 / 调整**

| 模块 | 说明 | 归属主题 |
|------|------|----------|
| `pages/SearchPage` | 搜索 Tab + 结果 | 搜索 |
| `pages/ArtistPage` | 可选 | 搜索 |
| `TopBar` | 搜索接线、快捷键聚焦 | 搜索 |
| `stores/contextMenuStore` | 菜单显隐与 payload | 右键菜单 |
| `components/common/ContextMenu` | 通用菜单浮层（portal） | 右键菜单 |
| `components/settings/*` | 新增「右键菜单」分组：拖拽排序列表 | 右键菜单 |
| `SongTable` / `QueuePanel` / 卡片网格 | 挂 `onContextMenu` | 右键菜单 |
| `stores/settingsStore` | 扩展 `contextMenu` 配置（复用 v0.1.2 prefs 层） | 右键菜单 |

## 5. 交互与状态

1. **搜索**：结果页 Tab 记忆本次会话；返回列表页不丢已填关键字。
2. **右键**：在空白处右键不弹自定义菜单（或仅弹「设置」入口，默认不弹）；拖拽排序时禁止同时打开菜单。
3. **右键配置**：改配置后菜单实时反映；拖拽排序期间菜单不弹出。

## 7. 非目标

**本版不做**

- 搜索纠错、联想下拉、语音输入
- 歌手完整主页（关注、MV、相似歌手）
- 右键菜单插件化 / 第三方动作

**移至后续版本**

| 主题 | 去向 |
|------|------|
| 登录凭证持久化（浏览器存储方案） | v0.1.4 |
