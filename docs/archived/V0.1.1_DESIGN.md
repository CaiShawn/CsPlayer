# CsPlayer v0.1.1 设计文档

相对 v0.1.0 的增量范围。基线见 `PHASE1_DESIGN.md`。

## 1. 目标

完善常驻导航与账号相关板块：顶栏、侧边栏重组、我喜欢 / 最近播放 / 唱片架，以及右侧歌词栏的显隐与收起。

## 2. 功能范围

### 2.1 顶栏（常驻）

| 区域 | 内容 |
|------|------|
| 左侧 | 软件名 **CsPlayer**；副标题 **Third-party web player for NCM** |
| 中间 | 搜索框（仅 UI，暂不接线） |
| 右侧 | 用户头像 + 昵称；点击弹出菜单 |

**头像菜单**

- 切换账号：弹层内嵌二维码登录，不离开当前页；成功后刷新库数据并关闭弹层
- 退出登录：清 session / 播放队列，回登录页

**账号隔离**

「我喜欢」「最近播放」等板块数据按当前登录账号（云端 cookie）隔离，不做跨账号本地合并。

### 2.2 侧边栏导航

```
首页          → /home
我喜欢        → /like
最近播放      → /recent
唱片架        → /shelf
音乐库        → /library   （原「我的音乐」更名）
```

- 我喜欢 / 最近播放 / 唱片架 与「首页」同级，样式沿用现有 NavItem
- 「音乐库」保留下级歌单/收藏入口（现有 LibraryPage 行为不变）

### 2.3 首页 `/home`（聚合页）

三张卡片入口，点击跳转对应路由：

| 卡片 | 路由 |
|------|------|
| 我喜欢 | `/like` |
| 最近播放 | `/recent` |
| 唱片架 | `/shelf` |

样式沿用现有设计风格（深色 + emerald 点缀）。

### 2.4 我喜欢 `/like`

- **数据源**：网易云账号自带「我喜欢的音乐」歌单（云端，设备间同步）
- 歌曲列表 + 播放全部 / 单曲播放
- **红心操作**：支持喜欢 / 取消喜欢，写云端；列表行可操作，播放条当前曲也可切换

### 2.5 最近播放 `/recent`

- **数据源**：云端听歌记录 `user/record`
- 默认展示 **50** 条，按时间倒序
- 可直接播放列表内歌曲

### 2.6 唱片架 `/shelf`

- **数据源**：当前账号已收藏专辑（与现有 `/user/albums` 相同）
- 专辑封面网格展示
- 点击进入专辑详情 `/album/:id`

### 2.7 右侧歌词栏

- **未播放**：自动隐藏
- **播放中**：可收起 / 展开（记住用户本次会话偏好即可）

## 3. 后端 API 增量

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/user/likes` | 我喜欢的音乐歌曲列表 |
| POST | `/api/song/{id}/like` | 红心开关（body: `like: boolean`） |
| GET | `/api/user/recent` | 最近播放，默认 limit=50 |

沿用：`/api/user/albums`、`/api/album/{id}`、`/api/song/{id}/{url,lyric,detail}`、`/api/auth/*`。

**SDK 对齐**

- 我喜欢歌单：在 `user_playlist` 中识别「我喜欢的音乐」（名称约定 / specialType），再用 `playlist_track_all` 拉全量
- 红心：优先 `like` 或对喜欢歌单的增删曲；方法名以 `MusicLibrary` 源码为准
- 最近播放：`record_recent_song`（按播放时间倒序；`user_record` 是听歌排行，不适用于此），解析为歌曲摘要列表

## 4. 前端路由与组件

```
/login
/           → MainLayout
  /home     HomePage          聚合三卡片
  /like     LikePage          列表 + 红心
  /recent   RecentPage        最近 50
  /shelf    ShelfPage         专辑网格
  /library  LibraryPage       音乐库（原逻辑）
  /playlist/:id
  /album/:id
```

**组件调整**

- `TopBar`（新）：品牌、搜索框占位、用户菜单
- `MainLayout`：接入 TopBar；侧边栏文案与路由更新
- `HomePage`、`LikePage`、`RecentPage`、`ShelfPage`（新）
- `LyricPanel`：无曲目不渲染；播放中可收起
- `SongTable`：可选 like 列 / 操作
- `authStore` / `playerStore`：菜单与歌词栏 UI 状态

## 5. 交互与状态

1. **切换账号**：弹层 QR（复用 `useQrLogin`）→ 803 成功 → `fetchMe` + 刷新当前库数据 → 关弹层。不先 logout，扫新码成功后替换会话。
2. **红心**：乐观更新 UI，失败回滚并提示。
3. **最近播放**：若需本端播放也进云端记录，可后续补 `scrobble`；本版以云端记录展示为主。
4. **搜索框**：`form` 防止意外提交；placeholder「搜索（即将推出）」；不请求后端。

## 6. 非目标（本版不做）

- 搜索真实结果
- 发现 / 排行榜 / 评论 / MV
- 本地红心或本地播放历史
- 打包发布
