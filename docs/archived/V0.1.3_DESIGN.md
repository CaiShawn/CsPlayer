# CsPlayer v0.1.3 设计文档

> 📦 **本文档已封存**（2026-09-24 · v0.1.3 验收通过）。内容为 v0.1.3 最终实现基线，不再更新；后续主题见 [`../V0.1.4_DESIGN.md`](../V0.1.4_DESIGN.md)。

相对 v0.1.2 的增量范围。基线见 `V0.1.1_DESIGN.md` / `V0.1.2_DESIGN.md`（同在 `docs/archived/`）。
本版两项主题：**搜索**、**右键菜单（可自定义）**（均已实现，验收后微调见 §9.4，验收过程见 §10）。

> 版本路线：v0.1.2 设置模块（已完成）→ **v0.1.3 搜索 + 右键菜单（已完成）** → v0.1.4 登录凭证持久化（`../V0.1.4_DESIGN.md`）。
> 依赖 v0.1.2 沉淀的 prefs 读写层（`settingsStore`）与主题 token，右键菜单配置复用 `csplayer:prefs:*`。

## 1. 目标

1. 接通顶栏**搜索**：单曲 / 专辑 / 歌手 / 歌单，进入结果页并可直接播放。
2. 实现**自定义右键菜单**：覆盖列表、卡片、队列等场景，条目可按用户偏好增删排序。

## 2. 功能范围

### 2.1 搜索

顶栏搜索框从占位改为真实功能。

**交互**

1. 输入防抖 300ms；`Enter` 提交（初版设计的放大镜按钮在验收前移除，提交只留 Enter）。
2. 有关键字时跳转 `/search?q=...`（可刷新、可分享 URL）。
3. 无关键字聚焦时可显示「最近搜索」（本地存 10 条，可清空）。
4. 全局快捷键：`/` 或 `Ctrl+K` 聚焦搜索框（输入框内不劫持）。
5. 清空：输入框内自绘细线 ×（隐藏 `input[type=search]` 原生 ×），点击清空并聚焦。

**结果页 `/search`**

| Tab | 内容 | 主操作 |
|-----|------|--------|
| 单曲 | 表格：曲名 / 歌手 / 专辑 / 时长 | 播放、下一首播、加入队列、喜欢 |
| 专辑 | 封面网格 | 进 `/album/:id` |
| 歌手 | 头像 + 名称 | 进歌手页（见下） |
| 歌单 | 封面网格 | 进 `/playlist/:id` |

- 顶栏输入与结果页关键字双向同步；结果内改关键字即时重搜。
- 分页或「加载更多」；空结果显示空态（区分「无结果」与「请求失败」）。
- 单曲支持「播放全部」（搜索结果作为队列）。

**后端**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | `kw`、`type=song\|album\|artist\|playlist`、`limit`、`offset` |

- 映射 SDK 搜索接口（`search_default` 等，以 `MusicLibrary` 为准）。
- 响应统一为 `{ items, hasMore, total }`；单曲映射 `SongSummary`，专辑/歌单复用 `AlbumBrief` / `PlaylistBrief`。
- 短 TTL 缓存（如 60s，key 含 `kw+type+page`），避免重复打上游。

**歌手页（可选最小闭环）**

- 路由 `/artist/:id`：热门歌曲（热门 50 首）+ 专辑列表；本版做「查看歌手」只读页，不做关注/收藏。
- 专辑列表独立分页：每页 30 张 + 「加载更多」（`GET /api/artist/{id}/albums`），翻完即止。
- 若工期紧，歌手 Tab 点击可先弹「即将推出」，优先保证单曲/专辑/歌单（实际未降级，已全量实现）。

### 2.2 右键菜单（可自定义）

**目标**：在应用内任意可操作对象上 `contextmenu` 弹出**自定义菜单**（阻止浏览器默认菜单），条目与顺序可由用户配置。

**触达对象**

| 对象 | 代表位置 |
|------|----------|
| 歌曲行 | 我喜欢、歌单/专辑详情、搜索结果、排行榜 |
| 播放队列项 | 右侧队列面板 |
| 当前曲 | 播放条封面 / 歌名区 |
| 专辑卡片 | 唱片架、搜索、音乐库 |
| 歌单卡片 | 音乐库 |

**内置动作（按对象过滤后展示）**

| 动作 | 歌曲 | 专辑 | 歌单 | 说明 |
|------|:----:|:----:|:----:|------|
| 播放 | ✓ | ✓ | ✓ | 替换队列或播该集 |
| 下一首播放 | ✓ | ✓ | ✓ | 插入队列 |
| 加入队列 | ✓ | ✓ | ✓ | 追加 |
| 喜欢 / 取消喜欢 | ✓ | | | 乐观更新 |
| 从队列移除 | ✓(队列) | | | 仅队列项 |
| 查看专辑 | ✓ | | | 跳转 |
| 查看歌手 | ✓ | ✓ | | 跳转 / 占位 |
| 复制链接 | ✓ | ✓ | ✓ | 复制 wyy（网易云）网页版链接 |
| 复制歌曲 ID | ✓ | | | 调试 / 分享 |

**自定义能力**

1. **设置 → 右键菜单**：按对象类型勾选「显示 / 隐藏」动作；上下拖拽排序；「恢复默认布局」。
2. 菜单末尾固定「自定义此菜单…」：直接跳设置对应分组，降低配置路径成本。
3. 配置存 `localStorage`（`csplayer:prefs:contextMenu`），与 v0.1.2 设置模块共用 prefs 层。
4. 隐藏全部非固定项时，仅剩「自定义…」与常用一两项，避免空菜单。

**菜单 UI**

- 定位：靠近光标，视口边缘自动翻转；`z-index` 高于队列面板。
- 交互：`Esc` / 点击外部 / 滚动关闭；支持方向键 + `Enter`（基础无障碍）。
- 样式：沿用顶栏下拉（`rounded-xl border-neutral-800 bg-neutral-900 shadow-xl`），图标位 + 文案；危险项（如移除）弱化红色。

**实现结构**

```
contextMenuStore   可见性、锚点坐标、目标 payload（song/album/playlist/queueIndex）
ContextMenu        通用浮层组件（portal）
contextActions     动作注册表 id → { label, icon, appliesTo, run }
prefs.contextMenu  每类对象的 id[]（有序 = 显示顺序）
```

- 右键时 `preventDefault()`，写入 store；组件树只挂一个 `ContextMenu` 实例。
- 动作 `run` 调现有 store / api（`playerStore`、`likesStore`、路由跳转），不新开服务层。

## 3. 后端 API 增量

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | 综合搜索，`type` 分型 |
| GET | `/api/artist/{id}` | 歌手详情（热门歌曲） |
| GET | `/api/artist/{id}/albums` | 歌手专辑分页（`{items, hasMore, total}`，歌手页每页 30 张 + 加载更多） |

右键菜单**无后端**（纯前端 prefs）。搜索缓存 TTL 建议加入 `settings.cache_ttl["search"] = 60`。

**SDK 对齐**

- 搜索类方法名以 `MusicLibrary` 源码为准（如 `search_default` / cloudsearch 系列）。
- 注意风控：搜索关键字过短或过频时在服务端限流（复用 `rate_limited`）。

## 5. 交互与状态

1. **搜索**：结果页 Tab 记忆本次会话；返回列表页不丢已填关键字。
2. **右键**：在空白处右键不弹自定义菜单（或仅弹「设置」入口，默认不弹）；拖拽排序时禁止同时打开菜单。
3. **右键配置**：改配置后菜单实时反映；拖拽排序期间菜单不弹出。

## 9. 附录：实现落定（v0.1.3）

§尾注提到的三个待细化点，在实现时按如下方案定稿。

### 9.1 搜索分型与空态文案

| type | 上游（cloudsearch 类型码） | items | total 字段 |
|------|------|------|------|
| `song` | 1 | `SongSummary`（按 privilege 标记不可播） | `songCount` |
| `album` | 10 | `AlbumBrief` | `albumCount` |
| `artist` | 100 | `ArtistBrief` | `artistCount` |
| `playlist` | 1000 | `PlaylistBrief` | `playlistCount` |

空态：无关键字 → 「输入关键字开始搜索」；有结果为空 → 「未找到与「kw」相关的结果」；请求失败 → 错误文案 + 重试按钮（与空结果明确区分）。

### 9.2 右键动作默认布局（= 合法动作 id 全集）

| 对象 | 默认顺序（id） |
|------|------|
| 歌曲（含队列项 / 当前曲） | `play` `playNext` `addQueue` `like` `removeFromQueue`（仅队列项） `viewAlbum` `viewArtist` `copyLink` `copySongId` |
| 专辑 | `play` `playNext` `addQueue` `viewArtist` `copyLink` |
| 歌单 | `play` `playNext` `addQueue` `copyLink` |

菜单末尾固定分隔线 + 「自定义此菜单…」（跳 `settings?group=contextMenu`）；全部隐藏时仅剩该项 + 「已隐藏全部条目」提示，不会出现空菜单。`copyLink` 复制 wyy（网易云）网页版链接（`music.163.com/song?id=` / `/album?id=` / `/playlist?id=`），便于分享到站外。

### 9.3 prefs schema 合并策略

```ts
// localStorage: csplayer:prefs:contextMenu
{ version: 1,
  song:     { order: string[], hidden: string[] },
  album:    { order: string[], hidden: string[] },
  playlist: { order: string[], hidden: string[] } }
```

- `order` 含隐藏项，数组顺序 = 菜单显示顺序；`hidden` 存被勾掉的 id。
- 合并规则：丢弃未知 id、补齐新增 id（保持默认相对顺序）、`hidden` 只保留合法 id；JSON 损坏 / 解析失败 → 整组回落默认布局（S3-2）。
- 配置独立于主 prefs（`csplayer:prefs:main`）存储，但由 `settingsStore` 统一读写；「清除本地数据」按 `csplayer:` 前缀一并清除。

### 9.4 验收后微调（同版迭代落定）

| 调整 | 说明 |
|------|------|
| 顶栏放大镜按钮移除 | 提交只保留 `Enter`；`SearchPage` 空态文案同步为「输入关键字开始搜索（Enter 提交）」 |
| 搜索框清除钮自绘 | 自绘细线 ×（SVG stroke-width 1），隐藏 `input[type=search]` 原生 × / 装饰，点击清空并聚焦 |
| 歌手专辑独立分页 | 新增 `GET /api/artist/{id}/albums?offset&limit`（每页 30，`{items, hasMore, total}`）；`ArtistDetail` 移除 `albums` 字段，专辑单一来源分页接口，detail 少一次上游调用 |
| `copyLink` 改复制 wyy 链接 | 全局统一复制网易云网页版链接（见 §9.2） |
| 提示框自动消失 | 全局 `Toast` 3s 自动关闭（可 ✕ 提前关闭），避免操作成功提示常驻 |
| 搜索表列宽 | `SongTable` 支持 `titleMaxWidth` / `durationWidth`，搜索页用 235 / 69px；若显挤可调至 72–76px |
