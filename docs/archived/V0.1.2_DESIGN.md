# CsPlayer v0.1.2 设计文档

相对 v0.1.1 的增量范围。基线见 `V0.1.1_DESIGN.md` / `PHASE1_DESIGN.md`。
本版一项主题：**设置模块（含 prefs 基础层与主题 token）**。均为当前代码未实现功能。

> 版本路线：v0.1.2 设置模块 → v0.1.3 搜索 + 右键菜单（`../V0.1.3_DESIGN.md`）→ v0.1.4 登录凭证持久化（`../V0.1.4_DESIGN.md`）。三版共四项主题，本版是后续两版的 prefs / 主题基础。

## 1. 目标

1. 建立可扩展的**设置中心**：外观（主题色）、播放、歌词、缓存等偏好，本地持久化。
2. 沉淀 **prefs 读写层**与**主题色语义 token**，供后续版本（右键菜单配置等）复用。

## 2. 功能范围：设置模块

**入口**

- 顶栏右上角齿轮按钮（与昵称并列）进入；位于用户菜单右侧。
- 形态：路由 `/settings`（便于深链与扩展），布局与现有页面一致，左侧分组锚点或顶部分栏。

**持久化**

- 前端 `localStorage`（key 前缀 `csplayer:prefs:*`），不强制后端同步。
- 版本号字段 `prefsVersion`，不兼容时重置为默认并保留备份。
- 「恢复默认」一键重置。

### 2.1 外观

| 偏好 | 默认 | 说明 |
|------|------|------|
| **主题色（强调色）** | `emerald` | 替换全局 `emerald-500` / `emerald-400` / `emerald-300` / `emerald-500/15` 等强调色角色 |
| 预设色板 | emerald / cyan / blue / violet / rose / amber / orange | 一键切换 |
| 自定义颜色 | — | 色板选择器 + HEX 输入，映射到同一「强调色」CSS 变量 |
| 界面密度 | 舒适 | 舒适 / 紧凑（影响列表行高、卡片间距） |
| 封面圆角 | 中 | 无 / 中 / 大（卡片与封面 `rounded` 一档） |

**主题色实现要点**

- Tailwind 侧收敛为语义 token：`--color-accent`、`--color-accent-soft`、`--color-accent-text`，由 CSS 变量驱动。
- 组件内逐步把裸 `emerald-*` 换成 `text-accent` / `bg-accent` / `border-accent` 等工具类（或 `@apply` / theme 扩展）。
- 自定义色同时生成 hover / active 透明度变体，保证播放主按钮、NavItem 激活态、进度条等对比度可读。
- 深色基底（`neutral-950`）本版固定，不提供浅色主题。

### 2.2 播放

| 偏好 | 默认 | 说明 |
|------|------|------|
| 记住音量 | 开 | 启动恢复上次音量 |
| 不可播放时 | 自动跳过 | **自动跳过 / 停止并提示**（避免无版权曲目在单曲循环下忙循环） |
| 刷新后恢复队列 | 开 | `sessionStorage` 保存 queue / index / quality，刷新后可继续 |
| 自动续播下一首 | 开 | 对应现有 `handleEnded`；关闭则播完停住 |

### 2.3 歌词

| 偏好 | 默认 | 说明 |
|------|------|------|
| 歌词字号 | 中 | 小 / 中 / 大（面板内 `text-sm` / `text-base` / `text-lg`） |
| 显示翻译 | 开 | 有 `tlyric` 时双行展示 |
| 高亮当前行 | 开 | 关闭则全词同色，仅滚动跟随 |

### 2.4 缓存

- 显示前端缓存占用估算（队列、图片可清）。
- 「恢复默认」：偏好一键重置为默认值。
- **清除本地数据**：prefs / 队列 / 缓存一次清空。

### 2.5 关于

- 版本号、开源声明、`docs` 链接（关于页，与「缓存」分组分开）。

## 4. 前端路由与组件

```
/login
/           → MainLayout
  /home
  /like
  /record
  /shelf
  /library
  /settings SettingsPage（新）
  /playlist/:id
  /album/:id
```

**新增 / 调整**

| 模块 | 说明 |
|------|------|
| `stores/settingsStore` | 外观 / 播放 / 歌词配置；读写 localStorage（`csplayer:prefs:*`） |
| `components/settings/*` | 色板选择、开关、设置分组控件 |
| `pages/SettingsPage` | 设置中心 |
| `TopBar` | 右上角齿轮「设置」入口（与昵称并列，当前页高亮） |
| `useAudioEngine` | 读「不可播放时」偏好，决定跳过或停止 |
| `playerStore` | 刷新恢复队列（`sessionStorage`）、记住音量 |
| `LyricPanel` | 字号 / 翻译 / 高亮偏好 |
| 全局 CSS 变量 | 主题色 token（`--color-accent*`） |

## 5. 交互与状态

1. **主题色**：改色立即生效（CSS 变量），无需刷新；自定义色做合法性校验（HEX6）。
2. **队列恢复**：仅恢复列表与索引，不自动播放（浏览器自动播放策略）；用户点击播放后从上次进度可选。
3. **不可播放偏好**：设为「停止」时，`!playable` 只 `setPlaying(false)` 并 toast，不调用 `handleEnded`。
4. **切换账号**：prefs 属于本机/浏览器，不随账号切换清空；队列恢复策略是否清空由「恢复队列」开关决定（换账号建议清云端无关队列）。
