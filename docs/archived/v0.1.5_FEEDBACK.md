## 已修复（2026-09）

- ✅（BUG）播放时偶尔会遇到在播放和暂停之间频繁切换，用户无法操作，刷新后好转
  （根因：play/pause 事件回写形成状态回声环 + AbortError 误判；已拆除回声、换曲即卸载旧音源）
- ✅（BUG）自动续播时，下一首歌的前几秒会播放上一首歌的内容
  （含补充现象「手动切歌时也会短暂播放上一首」；根因：换曲被误判为拖进度条把上一首 seek 回 0:00 重播 + 取 URL 空窗期旧曲继续播）
- ✅（功能）播放进度记录，刷新后仍保留原进度
  （按澄清实现：刷新后自动回到原进度；「刷新后自动播放」为可选设置，浏览器拦截方案见 设置 → 播放 → ⓘ）
