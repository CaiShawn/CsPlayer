# CsPlayer v0.1.2 设计文档

相对 v0.1.1 的增量范围。基线见 `V0.1.1_DESIGN.md` / `PHASE1_DESIGN.md`。  
本版三项主题：**设置模块**、**搜索**、**右键菜单（可自定义）**。均为当前代码未实现功能。

## 1. 目标

1. 建立可扩展的**设置中心**：外观（主题色）、播放、歌词、缓存等偏好，本地持久化。
2. 接通顶栏**搜索**：单曲 / 专辑 / 歌手 / 歌单，进入结果页并可直接播放。
3. 实现**自定义右键菜单**：覆盖列表、卡片、队列等场景，条目可按用户偏好增删排序。

## 2. 功能范围

### 2.1 设置模块

**入口**

- 顶栏用户菜单增加「设置」；也可从侧边栏底部齿轮进入。
- 形态：路由 `/settings`（便于深链与扩展），布局与现有页面一致，左侧分组锚点或顶部分栏。

**持久化**

- 前端 `localStorage`（key 前缀 `csplayer:prefs:*`），不强制后端同步。
- 版本号字段 `prefsVersion`，不兼容时重置为默认并保留备份。
- 「恢复默认」一键重置。

#### 2.1.1 外观

| 偏好 | 默认 | 说明 |
|------|------|------|
| **主题色（强调色）** | `emerald` | 替换全局 `emerald-500` / `emerald-400` / `emerald-300` / `emerald-500/15` 等强调色角色 |
| 预设色板 | emerald / cyan / blue / violet / rose / amber / orange | 一键切换 |
| 自定义颜色 | — | 色板选择器 + HEX 输入，映射到同一「强调色」CSS 变量 |
| 界面密度 | 舒适 | 舒适 / 紧凑（影响列表行高、卡片间距） |
| 封面圆角 | 中 | 无 / 中 / 大（卡片与封面 `rounded` 一档） |

**主题色实现要点**

- Tailwind 侧收敛为语义 token：`--color-accent`、`--color-accent-soft`、`--color-accent-text`，由 CSS 变量驱动。
- 组件内逐步把裸 `emerald-*` 换成 `text-accent` / `bg-accent` / `border-accent` 等工具类（或 `@apply` / theme 扩展）。
- 自定义色同时生成 hover / active 透明度变体，保证播放主按钮、NavItem 激活态、进度条等对比度可读。
- 深色基底（`neutral-950`）本版固定，不提供浅色主题。

#### 2.1.2 播放

| 偏好 | 默认 | 说明 |
|------|------|------|
| 记住音量 | 开 | 启动恢复上次音量 |
| 不可播放时 | 自动跳过 | **自动跳过 / 停止并提示**（避免无版权曲目在单曲循环下忙循环） |
| 刷新后恢复队列 | 开 | `sessionStorage` 保存 queue / index / quality，刷新后可继续 |
| 自动续播下一首 | 开 | 对应现有 `handleEnded`；关闭则播完停住 |

#### 2.1.3 歌词

| 偏好 | 默认 | 说明 |
|------|------|------|
| 歌词字号 | 中 | 小 / 中 / 大（面板内 `text-sm` / `text-base` / `text-lg`） |
| 显示翻译 | 开 | 有 `tlyric` 时双行展示 |
| 高亮当前行 | 开 | 关闭则全词同色，仅滚动跟随 |

#### 2.1.4 缓存与关于

- 显示前端缓存占用估算（队列、图片可清）。
- **清除本地数据**：prefs / 队列 / 缓存一次清空。
- 版本号、开源声明、`docs` 链接（关于页）。

**非设置范围（本版不做）**：多语言、浅色主题、音质默认档（播放条已提供选择）、听歌打卡 / scrobble、账号云端同步偏好。

### 2.2 搜索

顶栏搜索框从占位改为真实功能。

**交互**

1. 输入防抖 300ms；`Enter` 或点放大镜提交。
2. 有关键字时跳转 `/search?q=...`（可刷新、可分享 URL）。
3. 无关键字聚焦时可显示「最近搜索」（本地存 10 条，可清空）。
4. 全局快捷键：`/` 或 `Ctrl+K` 聚焦搜索框（输入框内不劫持）。

**结果页 `/search`**

| Tab | 内容 | 主操作 |
|-----|------|--------|
| 单曲 | 表格：曲名 / 歌手 / 专辑 / 时长 | 播放、下一首播、加入队列、喜欢 |
| 专辑 | 封面网格 | 进 `/album/:id` |
| 歌手 | 头像 + 名称 | 进歌手页（见下） |
| 歌单 | 封面网格 | 进 `/playlist/:id` |

- 顶栏输入与结果页关键字双向同步；结果内改关键字即时重搜。
- 分页或「加载更多」；空结果显示空态（区分「无结果」与「请求失败」）。
- 单曲支持「播放全部」（搜索结果作为队列）。

**后端**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | `kw`、`type=song\|album\|artist\|playlist`、`limit`、`offset` |

- 映射 SDK 搜索接口（`search_default` 等，以 `MusicLibrary` 为准）。
- 响应统一为 `{ items, hasMore, total }`；单曲映射 `SongSummary`，专辑/歌单复用 `AlbumBrief` / `PlaylistBrief`。
- 短 TTL 缓存（如 60s，key 含 `kw+type+page`），避免重复打上游。

**歌手页（可选最小闭环）**

- 路由 `/artist/:id`：热门歌曲 + 专辑列表；本版可先做「查看歌手」只读页，不做关注/收藏。
- 若工期紧，歌手 Tab 点击可先弹「即将推出」，优先保证单曲/专辑/歌单。

### 2.3 右键菜单（可自定义）

**目标**：在应用内任意可操作对象上 `contextmenu` 弹出**自定义菜单**（阻止浏览器默认菜单），条目与顺序可由用户配置。

**触达对象**

| 对象 | 代表位置 |
|------|----------|
| 歌曲行 | 我喜欢、歌单/专辑详情、搜索结果、排行榜 |
| 播放队列项 | 右侧队列面板 |
| 当前曲 | 播放条封面 / 歌名区 |
| 专辑卡片 | 唱片架、搜索、音乐库 |
| 歌单卡片 | 音乐库 |

**内置动作（按对象过滤后展示）**

| 动作 | 歌曲 | 专辑 | 歌单 | 说明 |
|------|:----:|:----:|:----:|------|
| 播放 | ✓ | ✓ | ✓ | 替换队列或播该集 |
| 下一首播放 | ✓ | ✓ | ✓ | 插入队列 |
| 加入队列 | ✓ | ✓ | ✓ | 追加 |
| 喜欢 / 取消喜欢 | ✓ | | | 乐观更新 |
| 从队列移除 | ✓(队列) | | | 仅队列项 |
| 查看专辑 | ✓ | | | 跳转 |
| 查看歌手 | ✓ | ✓ | | 跳转 / 占位 |
| 复制链接 | ✓ | ✓ | ✓ | 复制站内路径 |
| 复制歌曲 ID | ✓ | | | 调试 / 分享 |

**自定义能力**

1. **设置 → 右键菜单**：按对象类型勾选「显示 / 隐藏」动作；上下拖拽排序；「恢复默认布局」。
2. 菜单末尾固定「自定义此菜单…」：直接跳设置对应分组，降低配置路径成本。
3. 配置存 `localStorage`（`csplayer:prefs:contextMenu`），与设置模块共用 prefs 层。
4. 隐藏全部非固定项时，仅剩「自定义…」与常用一两项，避免空菜单。

**菜单 UI**

- 定位：靠近光标，视口边缘自动翻转；`z-index` 高于队列面板。
- 交互：`Esc` / 点击外部 / 滚动关闭；支持方向键 + `Enter`（基础无障碍）。
- 样式：沿用顶栏下拉（`rounded-xl border-neutral-800 bg-neutral-900 shadow-xl`），图标位 + 文案；危险项（如移除）弱化红色。

**实现结构**

```
contextMenuStore   可见性、锚点坐标、目标 payload（song/album/playlist/queueIndex）
ContextMenu        通用浮层组件（portal）
contextActions     动作注册表 id → { label, icon, appliesTo, run }
prefs.contextMenu  每类对象的 id[]（有序 = 显示顺序）
```

- 右键时 `preventDefault()`，写入 store；组件树只挂一个 `ContextMenu` 实例。
- 动作 `run` 调现有 store / api（`playerStore`、`likesStore`、路由跳转），不新开服务层。

## 3. 后端 API 增量

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search` | 综合搜索，`type` 分型 |

设置与右键菜单**无后端**（纯前端 prefs）。搜索缓存 TTL 建议加入 `settings.cache_ttl["search"] = 60`。

**SDK 对齐**

- 搜索类方法名以 `MusicLibrary` 源码为准（如 `search_default` / cloudsearch 系列）。
- 注意风控：搜索关键字过短或过频时在服务端限流（复用 `rate_limited`）。

```
/login
/           → MainLayout
  /home
  /like
  /record
  /shelf
  /library

  /settings SettingsPage（新）
  /artist/:id  ArtistPage（新，可降级）

```

**新增 / 调整**

| 模块 | 说明 |
|------|------|
| `stores/settingsStore` | 外观 / 播放 / 歌词 / 右键菜单配置；读写 localStorage |
| `stores/contextMenuStore` | 菜单显隐与 payload |
| `components/common/ContextMenu` | 通用菜单浮层 |
| `components/settings/*` | 色板选择、开关、拖拽排序列表 |
| `pages/SearchPage` | 搜索 Tab + 结果 |
| `pages/SettingsPage` | 设置中心 |
| `pages/ArtistPage` | 可选 |
| `TopBar` | 搜索接线、快捷键聚焦、用户菜单加「设置」 |
| `SongTable` / `QueuePanel` / 卡片网格 | 挂 `onContextMenu` |
| `useAudioEngine` | 读「不可播放时」偏好，决定跳过或停止 |
| `LyricPanel` | 字号 / 翻译 / 高亮偏好 |
| 全局 CSS 变量 | 主题色 token |

## 5. 交互与状态

1. **主题色**：改色立即生效（CSS 变量），无需刷新；自定义色做合法性校验（HEX6）。
2. **搜索**：结果页 Tab 记忆本次会话；返回列表页不丢已填关键字。
3. **右键**：在空白处右键不弹自定义菜单（或仅弹「设置」入口，默认不弹）；拖拽排序时禁止同时打开菜单。
4. **队列恢复**：仅恢复列表与索引，不自动播放（浏览器自动播放策略）；用户点击播放后从上次进度可选。
5. **不可播放偏好**：设为「停止」时，`!playable` 只 `setPlaying(false)` 并 toast，不调用 `handleEnded`。
6. **切换账号**：prefs 属于本机/浏览器，不随账号切换清空；队列恢复策略是否清空由「恢复队列」开关决定（换账号建议清云端无关队列）。

## 6. 非目标（本版明确不做）

- 浅色 / 多主题皮肤包
- 云同步设置、多设备配置
- 搜索纠错、联想下拉、语音输入
- 歌手完整主页（关注、MV、相似歌手）
- 右键菜单插件化 / 第三方动作
- 音质默认档设置（播放条已完成选择）

## 7. 验收清单

- [ ] 设置：主题色预设 + 自定义 HEX，全局强调色生效且对比可读

- [ ] 「不可播放时=停止」下无版权曲不切歌、不请求风暴
- [ ] 搜索：四类 Tab 可查；单曲可播放 / 加入队列；URL 可刷新
- [ ] 右键：歌曲 / 队列 / 专辑 / 歌单弹出自定义菜单，默认动作齐全
- [ ] 右键：设置中可隐藏与排序，菜单实时反映；「恢复默认布局」可用

- [ ] 无回归：登录、播放、喜欢、歌词、切换账号、音质选择不受影响
