## 2. 主题二：播放列表可钉住（方案三，前端）

### 2.1 形态

- **默认（抽屉）**：维持现状——点「列」弹出右侧浮层，面板外点击 / Esc 收起。
- **钉住（常驻）**：面板标题栏新增「图钉」按钮；钉住后占位常驻右侧（w-80），
  主内容区相应缩窄、**不再被浮层遮挡**；钉住态下「面板外点击收起」语义失效（不收起）。
- **状态记忆**：钉住与否 + 抽屉展开与否进 localStorage（`csplayer:prefs:*` 偏好前缀，
  拟 `csplayer:prefs:queuePinned` / `csplayer:prefs:queueOpen`），刷新后跟随（顺带完成 D1）；
  设置页「清除本地数据」清除后回落默认（抽屉 + 收起）。

### 2.2 待决问题（细化时定）

1. 钉住态是否支持**拖拽调宽**（拟 w-64 ~ w-96）？做则 +0.5 人日。
2. 与**歌词面板**同开的排布规则：(a) 队列钉住时歌词面板贴其左侧（两者都常驻）；(b) 互斥，只开一个。
   倾向 (a)，但需先确认窄屏可用性。
3. 窄窗策略：视口宽 < 阈值（拟 1100px）时钉住是否自动退化为浮层。
