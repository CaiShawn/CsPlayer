# CsPlayer

> **你的网易云，本该这么安静。**

**轻量级第三方网易云 Web 端播放器。不是另一个音乐 App，是一个只听歌的网页。**

1. 可自部署：扫码登录，凭证只存浏览器，后端零落盘。
2. 界面可定制：自定义右键菜单、侧栏滚动歌词、主题背景随心换。
3. 纯净播放：无广告、无推荐流，专注播放本身。

## 网抑云，启动！

> [!IMPORTANT]
> **平台要求：仅支持 Windows** —— 后端 SDK 仅提供 Windows 原生库，Linux / macOS 暂不可用，详见 `docs/docker/`。
>
> **安装环境**：Python 3.11+、Node.js 18+（含 npm）；依赖由启动脚本自动安装（后端 `pip install -r requirements.txt`、前端 `npm install`），手动启动则自行先装。

**一键启动**：

双击 `start.bat`（或 PowerShell 里 `.\start.ps1`）。

该操作会运行启动脚本，后端 / 前端各开一个终端窗口，安装依赖并启动服务，就绪后自动打开浏览器，使用网易云 App 扫码登录。



**手动启动**：

```powershell
# 启动后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 启动前端
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，使用网易云 App 扫码登录。

## Features

### 登录

- 扫码登录后，凭证自动保存，重启后端 / 刷新页面**免重新扫码**
- **多账号凭证库**（最多可保存 10 个），「切换账号」一键切回
- 登录页提供「快速登录」列表；设置页「账号凭证」可进行查看和编辑
- **LocalStorage** 保存凭证（浏览器端），**后端零落盘**

### 导航

- **首页** — 欢迎条与个人数据概览；各模块入口一键直达
- **我喜欢** — 云端红心歌曲；可「播放全部」；分批加载，滚动到底自动续拉
- **近来听** — 本地最近播放记录，分单曲/专辑/歌单
- **音乐库** — 展示个人创建与收藏的歌单，支持整单播放
- **自听榜** — 按「全部」与「最近一周」两个维度统计的听歌排行
- **唱片架** — 展示个人收藏的专辑；封面分批加载，滚动到底自动续拉

### 搜索

- 顶栏搜索框：支持搜索单曲、专辑、歌手与歌单，结果页可直接播放
- 快捷键：`/` 或 `Ctrl+K` 快速聚焦搜索框；最近搜索本地保存 10 条，可一键清空

### 播放

- 播放控制：播放 / 暂停 / 上一首 / 下一首，支持进度拖拽、播放模式切换；三档音质可选
- 播放队列：支持查看、切歌与拖拽排序，可「钉住」常驻侧栏；展开时点空白或按 `Esc` 收起；刷新后队列与播放进度自动恢复，可选自动继续播放
- 音量条：拖拽 / 滚轮微调，静音三态图标，自动记忆音量
- 歌词：逐行滚动、当前行高亮，翻译行可开关，字号三档；面板可收起并记忆状态
- 右键菜单：歌曲 / 队列 / 专辑 / 歌单上右键操作（播放、下一首播放、加入队列、查看专辑 / 歌手、复制链接、分享卡片等）；条目可自定义显隐与排序，支持键盘操作

### 分享卡片与拼贴卡

- **分享卡片** — 单曲 / 专辑 / 歌单一键生成图片卡片：比例可选、个人评论置底、背景纯色 / 渐变随心配，直接下载到本地
- **拼贴卡** — 唱片架里勾选多张收藏专辑，拼成一张封面拼贴图：最多 20 张，横 / 竖取向可切

### 个性化设置

- **主题外观** — 7 种主题色预设 + 自定义颜色；封面圆角可调
- **自定义背景** — 本地图片（自动压缩、仅存本机），不透明度 / 模糊 / 缩放 / 位置可调
- **播放习惯** — 不可播放时跳过或停止、刷新后是否自动播放等
- **数据管理** — 本地数据分类占用一目了然，可一键恢复默认或清除
