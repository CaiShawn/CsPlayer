# CsPlayer

> **你的网易云，本该这么安静。**

**轻量级第三方网易云 Web 端播放器。不是另一个音乐 App，是一个只听歌的网页。**

1. 可自部署：扫码登录，凭证只存浏览器，后端零落盘。
2. 界面可定制：自定义右键菜单、侧栏滚动歌词、主题背景随心换。
3. 纯净播放：无广告、无推荐流，专注播放本身。

## 魔改网抑云，启动！

> [!IMPORTANT]
> **平台要求：仅支持 Windows** —— 后端 SDK 仅提供 Windows 原生库，Linux / macOS 暂不可用，详见 `docs/docker/`。
>
> **安装环境**：Python 3.11+、Node.js 18+（含 npm）；依赖由启动脚本自动安装（后端 `pip install -r requirements.txt`、前端 `npm install`），手动启动则自行先装。

**一键启动**：双击 `start.bat`（或 PowerShell 里 `.\start.ps1`）——自动装依赖，后端 / 前端各开一个终端窗口，就绪后自动打开浏览器。

手动启动（与脚本等价）：

```powershell
# 启动后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 启动前端
cd frontend
npm install
npm run dev
```



打开 http://localhost:5173 ，使用网易云 App 扫码登录。

## Features

### 登录

- 扫码登录后凭证保存在浏览器本地，重启后端 / 刷新页面**免重新扫码**，自动静默恢复会话
- **多账号凭证库**：登录过的每个账号凭证都保留在本机（最多 10 个），「切换账号」一键切回、**免重新扫码**
- 登录页提供「快速登录」列表；设置「账号凭证」可查看 / 单独移除 / 一键清空
- 登录凭证仅保存在浏览器（localStorage），**后端零落盘**

### 导航

- **首页** — 欢迎条与个人数据概览（我喜欢 / 歌单 / 收藏专辑）；4 个模块入口一键直达；**最近播放**本地记录 50 条，点击续播、可清空
- **我喜欢** — 红心歌曲与网易云云端实时同步，各设备之间保持一致；「播放全部」立即开播、后台自动补全整份歌单；长列表分批加载，滚动到底自动续拉
- **我的歌单** — 包含你创建的与收藏的歌单，支持整单播放
- **自听榜** — 按「全部」与「最近一周」两个维度统计的听歌排行
- **唱片架** — 收藏的专辑以封面墙形式展示，便于快速查找；封面分批加载，滚动到底自动续拉

### 搜索

- 顶栏搜索框：支持搜索单曲、专辑、歌手与歌单，结果页可直接播放
- 快捷键：`/` 或 `Ctrl+K` 快速聚焦搜索框；最近搜索本地保存 10 条，可一键清空

### 播放

- 播放 / 暂停 / 上一首 / 下一首，支持进度拖拽
- 四种播放模式：顺序播放、列表循环、单曲循环、随机播放
- 多档音质可选：标准、HQ、SQ
- 播放队列：支持查看、切歌与拖拽排序，各行标注来源（歌单 / 专辑 / 歌曲等）；展开时**点击队列外任意位置**（或按 `Esc`）自动收起；刷新页面后队列与**播放进度**自动恢复，可选自动继续播放
- 音量条：支持拖拽 / 滚轮微调，百分比气泡提示，静音三态图标；音量自动记忆，下次打开保持上次的设置

### 歌词

- 逐行歌词随播放进度自动滚动，当前行高亮显示
- 支持翻译行显示，可按需开关
- 字号提供小、中、大三档
- 歌词面板可收起，便于浏览其他内容，并记忆展开 / 收起状态

### 右键菜单

- 歌曲、播放队列、当前曲、专辑与歌单卡片上右键即可操作：播放、下一首播放、加入队列、喜欢、查看专辑 / 歌手、复制网易云网页版链接等
- 菜单条目可自定义：「设置 → 右键菜单」中按对象勾选显隐、拖拽排序，一键恢复默认布局
- 靠近光标弹出、视口边缘自动翻转；支持方向键 + Enter 键盘操作

### 个性化设置

- **主题外观** — 提供 7 种主题色预设，支持自定义颜色；界面密度与封面圆角可调
- **自定义背景** — 本地背景图片（自动压缩、仅存本机），不透明度 / 模糊 / 缩放 / 拖拽移动可调，一键关闭；开启后界面表面半透明透出背景
- **播放习惯** — 遇到无法播放的歌曲时可选择跳过或停止，可设置是否自动播放下一首；「刷新后自动播放」可开关
- **歌词设置** — 字号、翻译行、当前行高亮均可独立控制
- **数据管理** — 支持一键恢复默认设置或清除本地数据

### 故障处理

- 单曲播放失败时可直接点击「重试」，无需刷新页面
- 播放过程中的临时故障会被自动处理，不影响后续播放
- 刷新后没有自动播放？多为浏览器自动播放策略拦截（页面会提示「浏览器阻止了自动播放」）：在站点设置里**允许自动播放**即可，详见下文

> ### 自动播放设置（浏览器侧）
>
> 开启「刷新后自动播放」仍被拦时，在浏览器里为本站放行即可（应用内入口：设置 → 播放 → 「刷新后自动播放」 ⓘ）：
>
> - **Chrome**：桌面版已移除「自动播放」站点设置，推荐用**媒体参与度**自动放行——在本站正常听歌一段时间后 Chrome 自动放行（`chrome://media-engagement` 可查本站分数）；开发机可 `chrome://flags/#autoplay-policy` →「No user gesture is required」，或启动参数 `--autoplay-policy=no-user-gesture-required`；另确认 `chrome://settings/content/sound` 中本站未被静音
> - **Edge**：地址栏 🔒 图标 → 「网站设置」→「媒体自动播放」→ 允许；或 `edge://settings/content/mediaAutoplay` 加入允许名单
> - **Firefox**：地址栏 🔒 图标 → 关闭「阻止音频自动播放」；或 `about:preferences#privacy` → 权限 → 自动播放 → 音频「允许」
> - **Safari**：设置 → 网站 → 自动播放 → 对本站选「允许所有自动播放」

## About
