# CsPlayer

**轻量级**第三方网易云 Web 端播放器。扫码登录，浏览「**我喜欢**」与「**收藏专辑**」；**侧栏歌词**与**自定义主题**——自部署、无广告、无推荐流，静静听歌。

## 网抑云，启动！

```powershell
# 启动后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 启动前端
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，使用网易云 App 扫码登录。

## Features

### 音乐库

- **我喜欢** — 红心歌曲与网易云云端实时同步，各设备之间保持一致
- **我的歌单** — 包含你创建的与收藏的歌单，支持整单播放
- **自听榜** — 按「全部」与「最近一周」两个维度统计的听歌排行
- **唱片架** — 收藏的专辑以封面墙形式展示，便于快速查找

### 播放

- 播放 / 暂停 / 上一首 / 下一首，支持进度拖拽
- 四种播放模式：顺序播放、列表循环、单曲循环、随机播放
- 多档音质可选：标准、较高、超高、无损、Hi-Res
- 播放队列支持查看与切歌；关闭页面后再次打开，队列自动恢复
- 音量自动记忆，下次打开保持上次的设置

### 歌词

- 逐行歌词随播放进度自动滚动，当前行高亮显示
- 支持翻译行显示，可按需开关
- 字号提供小、中、大三档
- 歌词面板可收起，便于浏览其他内容

### 个性化设置

- **主题外观** — 提供 7 种主题色预设，支持自定义颜色；界面密度与封面圆角可调
- **播放习惯** — 遇到无法播放的歌曲时可选择跳过或停止，可设置是否自动播放下一首
- **歌词设置** — 字号、翻译行、当前行高亮均可独立控制
- **数据管理** — 支持一键恢复默认设置或清除本地数据

### 故障处理

- 单曲播放失败时可直接点击「重试」，无需刷新页面
- 播放过程中的临时故障会被自动处理，不影响后续播放
